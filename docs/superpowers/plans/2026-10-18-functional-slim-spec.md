# seltool-go 保功能瘦身需求约定

## 用户目标

只交付方案，由用户安排实施。保留原作者 selenium-tool 的用户可见功能，并保留当前新增的 CookieCloud Web设置及自动/手动导入；优先完成验收，再尽可能瘦身。访问地址改用 `http://内网地址:8081`。

## 本轮授权边界

只做只读核验与方案文档，不修改生产业务代码、镜像、配置、账号、CookieCloud凭据、目标列表或站点任务。内网地址 的登录页与认证状态接口现已返回200，现有端口映射无需调整。该地址沿用现有 NodeBabyLink/虚拟网络访问路径，不将其认定为Tailscale。

## 功能保留边界

- Web登录/注册/登出、CSRF、主题和页面入口；目标普通编辑与模板约束。
- CookieCloud远端读取、密码不回显、保存热更新、缓存回退、准确的连接诊断。
- Chromium完整JavaScript、Cookie/HTTPOnly/localStorage、预热、图片控制与后缀资源拦截。
- 手动/启动/定时执行、单目标/批量失败重试、并发互斥、每目标7条历史。
- Webhook启动/失败/任务汇总通知。
- 完整有界面浏览器、中文显示、Xvfb/窗口管理、带密码VNC/noVNC、鼠标键盘、重连、实际剪贴板能力不退化。
- 当前新增的自动识别/手动导入、去重、预览；保留真实www等主机名、URL协议/路径/查询参数。

功能对等不是原版错误逐字复制：不能把登录误判为成功、把缓存冒充远端连通，也不能为体积隐藏/删除功能。驱动参数因CDP架构不再需要时应明确告知迁移差异，不安装无用chromedriver来形式兼容。
